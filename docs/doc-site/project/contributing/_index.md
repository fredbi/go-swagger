## How to contribute?

{{% notice style="info" %}}
A quick guide on how to contribute to `go-swagger` and to the family of the `go-openapi` repositories
may be found [there](https://go-openapi.github.io/doc-site/contributing/index.html).
{{% /notice %}}

You are welcome to clone this repo and start helping the `go-openapi` community:

```cmd
git clone https://github.com/go-swagger/go-swagger
```

Have an idea? A problem? Engage the conversation on our discord channel [![Discord Channel][discord-badge]][discord-url].
