## init

```cmd
Usage:
  swagger [OPTIONS] init <config | spec>

initialize a swagger spec document

Application Options:
  -q, --quiet                  silence logs
      --log-output=LOG-FILE    redirect logs to file

Help Options:
  -h, --help                   Show this help message

Available commands:
  config  initialize a config file for go-swagger
  spec    initialize a swagger spec

```
